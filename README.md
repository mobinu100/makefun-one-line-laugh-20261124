# The One-Line Laugh

Entry for [The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f) on make.fun.

The program writes one funny line to `/output/entry.txt`:

> I finally fixed my sleep schedule by going to bed at 9 p.m., then lay awake until 3 a.m. congratulating myself on the discipline.

## Run

```sh
node main.ts
```

`main.ts` is copy-only: it writes the final line (a constant) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). No network, no generation at grade time.
